# Olymp Bot

هذا مشروع بوت لتطبيق Olymp Trade باستخدام بايثون.

## الملفات
- `olymp_bot.py` : ملف البوت الرئيسي.
- `requirements.txt` : مكتبات بايثون اللازمة لتشغيل البوت.

## طريقة التشغيل
1. ضع التوكين (`TOKEN`) والايدي (`CHAT_ID`) في `olymp_bot.py`.
2. تأكد أن `requirements.txt` موجود في جذر المشروع.
3. على Render: أنشئ Web Service جديد واربط المشروع من GitHub.
4. Render سيقوم بتثبيت المكتبات وتشغيل البوت تلقائياً.

## ملاحظات
- يرسل البوت رسالة كل دقيقة.
- لتخصيص البوت، عدل على `olymp_bot.py` حسب احتياجاتك.
